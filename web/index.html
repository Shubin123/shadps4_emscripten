🕹 shadPS4 Web

PlayStation 4 Emulator — WebAssembly attempt, in progress

shadPS4 upstream· this repo· PROJECT.md
Nothing below runs a game. shadPS4 runs PS4 (x86-64) code directly on the host CPU instead of emulating it, which WebAssembly can't do at all — so unlike a Citra/Azahar-style port, there was no existing CPU interpreter to carry over. One is being built from scratch (register file, flags, control flow — tested, see PROJECT.md), but it isn't wired into a buildable shadPS4+Emscripten binary yet. The settings below reflect where things are, or are heading, not what works today.

⚙ CPU▾

Not a choice — shadPS4 has no other way to run guest code in a browser. Direct host-CPU execution (what every other shadPS4 build does) is impossible inside WebAssembly.
