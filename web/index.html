shadps4_web

An in-progress WebAssembly build of shadPS4. Nothing here runs a game yet — see below.

Why there's no "load a game" button that does anything

shadPS4 runs PS4 (x86-64) game code directly on the host CPU rather than emulating it, which WebAssembly has no way to do at all. Making that work means building a real, from-scratch x86-64 interpreter first — not something a browser page can route around. That interpreter exists and is tested, but it isn't wired into a buildable shadPS4+Emscripten binary yet, so there is no .wasm module for this page to load. Full details and current status: PROJECT.md.
